1번 과제입니다. 이제 GET 요청을 모두 다 만든 것에 이어서 이제는 2번째 파트인 POST 요청 처리를 만드는 걸 시작하게 되었습니다.
POST 요청을 처리하는 컨트롤러 상-변수인 locationsCreate를 만든 틀을 가지고 완성하게 되었습니다.

내용은 다음과 같습니다.
Mongoose를 통해서 데려온 DB를 지정한 상-변수인 Loc의 create 메서드를 사용합니다.
create 메서드에 name, address, facilities 등 필요한 정보 속성들을 모두 기재합니다.
기재할 때 req.body.[속성명] 이런 식으로 각 속성에 매칭되는 Form 정보들을 각각 지정했습니다.
facilities의 경우 split 메서드를 사용하여 데이터의 "," 문자를 처리하여 추가하고,
coords의 경우 type을 Point로 지정해주고, 내부 속성인 coordinates에 parseFloat 메서드를 사용하여 lng, lat 값을 가지고 왔습니다.
openingTimes의 경우 각 요일마다 달라지는 여러 객체들을 추가하고 각각 내부 속성을 req.body에서 데리고 왔습니다.
(예) openingTimes: [{ days: req.body.days1 ... }, { days: req.body.days2 ... }]...

다음으로 추가가 정상적으로 되면 그 추가한 것에 해당하는 location을 콜백 함수에서 받아서 else 파트에서 201 상태 코드와 함께
json 메서드로 출력시켜주는 원리입니다. 
(예) res.status(201).json(location);

만약 에러, err가 잡힌다면 if-else문의 if (err)문에 걸려서 400 에러 코드와 함께 err 자체를 출력시켜주게 됩니다.
또 유효성 검사를 더 잘할 수 있도록 models의 location.js의 스키마에서 address에 required: true 지정을 추가했습니다.
이름이 같지만 주소가 다 다른 경우도 은근 있기 때문에 유효성 검사를 강화했습니다.
