마지막 과제입니다. 메인 장소/서브 리뷰 다큐먼트 DELETE 요청을 처리하는 컨트롤러 상-변수인 locationsDeleteOne, reviewsDeleteOne을 만든 틀을 가지고 완성하게 되었습니다.
삭제라서 간단한 부분도 있습니다.

locationsDelete부터 설명하겠습니다.
req.params에서 locationid를 가져옵니다. 이게 없으면 삭제 자체를 못하므로
if문에서 이를 검사하여 if (!locationid)에서 걸리면 return res문에 가서 404 에러 코드와 장소 없음이라는 메시지를 json으로 출력합니다.
걸리지 않으면 locationid가 정상적으로 있다는 뜻이니 try-catch문으로 갑니다.

이 id를 findByIdAndDelete 메서드에 줘서 우리가 원하는 문서가 찾은 뒤 삭제될 수 있게 한 뒤 exec() 메서드에 연결하여 실행시킵니다.
원래 문서는 const 상-변수인 location에 저장되게 합니다. (findByIdAndRemove에서 Remove가 Delete로 변경되었습니다.)
만약 location이 애초에 존재하지 않는다면 locationid로 원래 문서를 찾을 수 없다는 뜻이라, 404 에러 코드와 장소 코드로 못 찾았다고 메시지를 출력하도록
if문을 구성했습니다.

이 if문에 걸리지 않는다면 정말로 삭제가 된 것으로 에러가 없는 이상 return res문을 만나 204 상태 코드와 null을 json으로 출력합니다.
삭제가 되었기에 딱히 출력하는 것이 없는 것입니다.

만약 중간 과정에서 에러가 발생했다면 catch문에 걸려 err를 감지, 404 에러 코드와 err 자체 정보를 출력했을 겁니다.

다음은 reviewsDeleteOne입니다.
리뷰 삭제에 필요한 문서 메인 문서 id와 리뷰 서브 문서 id를 모두 req.params에서 가져옵니다.
이후 두 id 중 하나라도 존재하지 않는다면 작업을 할 수 없으므로 if (!locationid || !reviewid) 문에서 이를 처리합니다.
만약 조건에 걸린다면 return res문으로 404 에러 코드와 두 id가 제대로 가져와지지 않았다고 알려주는 메시지를 출력합니다.

조건에 걸리지 않는다면 두 id 모두 잘 있다는 뜻이니 try-catch문으로 넘어갑니다.
아까와 마찬가지로 location이라는 const 상-변수에 findById 메서드를 쓰되, 이번에는 바로 삭제하지 않고
locationid를 전달하여 찾은 뒤 거기서 select 메서드로 reviews만 선택해서 exec에 넘깁니다.

이후 location이 존재하지 않는다면 if문에서 이를 감지하여 404 에러 코드와 이에 따른 메시지를 출력하는 것은 똑같습니다.
다음 검사에서는 location에 리뷰들(reviews)가 존재하는 지와 갯수(길이)가 0보다 큰 1 이상인 지를 확인하는 조건을 if문으로 거칩니다.
여기를 통과한다면 reviews가 정상적으로 있다는 뜻입니다. 통과하지 못할 경우, else문에서 404 에러 코드와 삭제할 리뷰가 없다는 메시지를 출력하게 됩니다.

다음으로 URL에서 가져온 reviewid를 location.reviews.id에 넣어서 우리가 삭제할 리뷰를 지정해서 review라는 const 상-변수에 넣습니다.
다음으로 review가 혹시 존재하지 않는 것일 수 있으니 if문에서 if (!review) 문으로 차단하여 return res문에 들어가
404코드와 리뷰가 존재하지 않는 메시지를 출력하게 할 수 있습니다.

여길 지나간다면 삭제할 리뷰가 존재하는 리뷰인 건 확실합니다.
이제 Delete 메서드로 이를 삭제한 뒤, location.save 메서드로 이를 최종 저장합니다. (remove 메서드가 Delete 메서드로 변경되었습니다.)
리뷰가 삭제되면 전체 레이팅에도 영향이 가므로 updateAverageRating에 장소 문서의 id를 전달하여 레이팅 업데이트를 명령한 뒤,
모든 작업이 끝나면 return res에서 204 상태 코드와 null을 출력하게 하는 구조입니다.

마지막으로 중간에 err, 에러가 발생한다면, catch문에 들어가서 400 에러 코드와 err 에러 자체 정보를 출력하게 될 것입니다.
모든 출력 화면과 소스 코드는 첨부 파일에서 확인하실 수 있습니다.
