첫번째 과제입니다. 이제는 API를 통해 DB에 리뷰를 추가하는 것을 구현하기 시작했습니다.
사용자가 입력한 폼 데이터를 가져와서 처리하고 그것을 API에게 포스팅하기 위해 이번 과제를 시작합니다.

리뷰는 Add Review 버튼을 클릭해서 추가되게 만들 것입니다.
먼저, 버튼을 클릭하면 뜨는 리뷰 폼 사이트에 대한 설정을 시작했습니다.

리뷰 폼에서는 당연히 리뷰가 추가되는 "장소"의 ID가 필요하여 URL 안에 Location ID를 첨가했습니다.
이를 위해 Add Review의 페이지 라우트에 location 파라미터를 추가했습니다.

.route 명령어에 '/location/:locationid/review/new'를 기재하여 URL에 첨가를 완료했습니다.
기존의 get 라우터 이외의 post 라우터를 doAddReview로 정해줬습니다. 여기서 리뷰 추가가 이뤄집니다.

Add Review 버튼에 지정된 href에 locationID를 추가해야 위에서 변경한 명령어의 루트를 갈 수 있으니,
a 태그에 매칭된 버튼에 대하여 태그의 href 경로에 `/location/${location._id}/review/new`를 넣어서
경로를 완성했습니다. 이제 버튼을 누르면 장소의 ID가 넘어가게 됩니다.

당연히 리뷰 폼이니 get 요청을 post 요청으로 변경했으며, 더 이상의 경로 변경은 이뤄지지 않아 action은 공백란으로 뒀습니다.
이후 이에 대해서 "리뷰 추가 기능 및 사이트"를 구현하기 위해 1차적으로 변경한 컨트롤러의 구조는 다음과 같습니다.

doAddReview를 server의 컨트롤러로 추가, addReview 컨트롤러에서 getLocationInfo 컨트롤러를 호출하고
이에 콜백으로 renderReviewForm 컨트롤러를 사용하는 구조, getLocationInfo는 가져온 장소 ID를 기반으로 장소 정보를 가져온 뒤
콜백으로 넘깁니다. 

기존 locationInfo는 getLocationInfo 컨트롤러에서 renderDetailPage 컨트롤러에 응답, 반응, 데이터를 그대로 넘겨서
장소 세부 페이지를 렌더링하는 걸로 변경해서 기능 자체는 그대로 유지하게 했습니다.

마지막으로 renderReviewForm 컨트롤러를 수정하여 넘겨 받은 데이터 중 name, 즉 장소의 이름을 이용하여
장소 리뷰 폼 사이트인 location-review-form에서 title과 pageHeader에 ${name} 이런 식으로 문법을 작성하여
이름을 여기에 다 갈아끼워서 출력되게 만들었습니다.

출력 사진에서 보시는 것처럼 정상적으로 페이지 자체의 이름과 내부의 Review 뒤에 오는 이름이 해당 "장소" ID(URL에서 데리고 온 것)에
맞는 이름이라는 것을 확인하실 수 있으며 출력도 잘 되는 것을 알 수 있습니다.
