컨트롤러는 정상적인 상황만이 아닌 비정상적인 에러 상황도 처리할 수 있어야합니다.
그치만 이전의 컨트롤러는 그런 부분이 전혀 구현되어있지 않았습니다.
그래서 에러 코드를 출력하거나 에러 메시지를 출력하여 오류를 알려주고 처리할 수 있도록
locationid가 포함되어 있지 않은 경우, findById 메서드가 장소 데이터를 반환하지 않는 경우,
에러를 반환하는 경우, 총 3가지 에러를 처리할 수 있게 만들었습니다.

먼저, locationid가 애초에 포함되어 있지 않다면 오류가 날 수밖에 없으니
그건 error로 처리하게 하면 됩니다. catch문으로 아까처럼 똑같이 구현했습니다.
대신 400 에러 코드를 출력하되, 이번에는 err를 json문에 넣어서 에러 자체를 출력하게 했습니다.

다음으로 if문을 활용하여 location이 존재하지 않는 경우, 즉 findById가 반환을 하지 않아
location 내부가 텅 비어있는 상태의 경우 if (!location) 조건에 걸리게 했습니다.
만약 그런다면 내부로 들어가 return res문으로 들어갑니다.
그 경우 404 에러 코드를 status로 출력하고, json 메서드에 메시지를 출력하게 했습니다.
ex) .json({ "message": "location not found" });

정상 상태라면 if문에 걸리지 않고 그 아래에 있는 일반 응답문인 return res를 만나서
200 상태 코드를 status로 출력하고, json 메서드로 location을 출력하게 했습니다.
이러면 DB에서 정상적으로 가져왔을 경우 장소 정보가 출력됩니다.

만약 그렇지 않다면 if문에 걸려서 에러 메시지가 출력되게 될 것입니다.
첨부한 실습 사진에서 이를 확인하실 수 있습니다.
정상적인 id라면 장소 정보를, 아니라면 에러 메시지가 나오는 것을 보실 수 있습니다.
